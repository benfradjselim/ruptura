# Mission P1-sources

- Component: C1-sources and C2-catalog
- Allowed paths: workdir/internal/sources/, workdir/go.mod, workdir/go.sum
- Input contract: a Prometheus-compatible HTTP API at a base URL, a bearer token, and an `*http.Client`.
- Output contract:
  - `sources.LoadCatalog() (Catalog, error)` reads an embedded `catalog.yaml`.
  - `Signal{Name, Mode, Usage, Capacity, Restarts string}` where the last three are PromQL strings.
  - `sources.Thanos.Collect(ctx, Signal) ([]Reading, error)`.
  - `Reading{Namespace, Pod string; Usage, Capacity float64; Restarts int; At time.Time}`.
  - Joins the three queries on namespace and pod. Missing capacity gives Capacity 0. Missing usage drops the pod.
  - `sources.NewInClusterThanos(url string) (*Thanos, error)` uses the pod token and trusts both `ca.crt` and `service-ca.crt` from the service account directory. Skip `service-ca.crt` when absent.
- First catalog entry, `memory_saturation`, mode `saturation`:
  - usage: `sum by (namespace,pod) (container_memory_working_set_bytes{container!="",container!="POD"})`
  - capacity: `sum by (namespace,pod) (kube_pod_container_resource_limits{resource="memory"})`
  - restarts: `sum by (namespace,pod) (kube_pod_container_status_restarts_total)`
- Numeric gate: tests cover the join, missing capacity, missing usage, HTTP error, Prometheus error status, and catalog loading. Coverage at least 80 percent.
- Proof command: `cd workdir && GOFLAGS=-p=1 go test -cover ./internal/sources`
- Constraints: Go 1.18, `InsecureSkipVerify` forbidden everywhere, tokens never logged, 15 second request timeout, `yaml.v3` already in go.mod, table-driven tests, godoc on exported symbols, English only.
- Stop rule: 2 attempts without score gain, return to the lead.
- Report: score before and after, changed files, blockers, 150 words maximum.
